A make.fun bounty entry: one out-of-office email auto-reply of at most 200 characters, painfully honest about the sender's inbox yet polite enough to survive being forwarded to a manager.

`main.ts` writes the entry to `/output/entry.txt`. Run it with Node 22:

```sh
node main.ts
```

The entry: an honest admission about 847 unread emails, and the promise that yours will be answered the moment the dread lifts — with the same care as always.
